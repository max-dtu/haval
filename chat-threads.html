Choose model source

WebLLM (Browser)

Runs locally in your browser using WebGPU. No backend. Performance depends on your device GPU and memory.

⚠️ Lower limits improve speed and reduce browser memory usage.

Ollama (Local Server)

Connects to a local Ollama instance. Parameters map directly to Ollama API fields.

⚠️ Some models may ignore certain parameters depending on backend support.

Remote API

Uses external LLM providers. Parameters are sent directly in API requests.

⚠️ Some APIs may ignore unsupported parameters or override them server-side.
